---
description: "选一个历史任务，把它的上下文加载到当前窗口接着做"
argument-hint: "[任务名/编号/会话ID]（可留空，留空则弹出选择）"
---

用户要恢复历史任务的上下文。

参数（可能为空）：`$ARGUMENTS`

执行步骤：

1. 如果参数为空 → 读 `skills/context-resume/SKILL.md` 的「流程 A」照做（列出最近任务 → 弹选择 → 加载 → 复述）。
2. 如果参数是编号或会话 ID → 直接 `node bin/cr.js load <参数>`，然后 `Read` 输出的 `RESUME_MAIN`，复述「这个任务在做什么 / 做到哪 / 下一步」。
3. 如果参数是任务名 → 先 `node bin/cr.js list --json` 做模糊匹配，唯一命中就直接加载，多个命中就弹选择。

注意：加载后先复述再动手，不要凭印象编造「上次做到哪」。
